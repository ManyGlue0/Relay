Relay 0.7.1 fixes long Agent sessions and counts what models read.

### New

- **Tokens read.** Settings → Stats now counts what the models read, not only what they wrote: every request of a reply, since an agent reads the whole conversation again at each step. A tile and a Read column in the By model table; each bar in the chart is the day's total, and hovering it shows read and written apart.

### Fixed

- **Long sessions summarize in time.** The summary near the end of a model's context could fail to start, letting a request fill the whole context. Relay now also counts what it's about to send, not only what the last reply measured.
- **Summaries wait for slow servers.** Writing a summary gave up after two minutes ("The server took too long to answer"), though reading a long session can take a local server longer. It now waits as long as the server keeps working, like a reply, and Stop still ends it.
- **Commands in Relay's own workspaces.** In a session without a folder picked, commands that named a file in the workspace were refused as "reading credentials", in every mode. They run now; Relay's own data beside the workspace is still off limits.
- **The Stats chart's tooltip** sits centered on its bar again and stays inside the chart at the edges.
