The first public release of **Relay**, a calm chat client for your models on Windows 11: local servers like Ollama, LM Studio and llama.cpp, or any OpenAI-compatible API, in one native window that lives in the [Holster](https://github.com/ManyGlue0/Holster) dock.

**Download** `Relay_0.4.0_x64-setup.exe` below and run it. It installs for your user only (no admin rights). From now on, Settings → About → **Check** updates Relay in place.

### What's in it

- **Any OpenAI-compatible endpoint**, with presets for Ollama, LM Studio, llama.cpp, vLLM, OpenAI, Anthropic, SpaceXAI and OpenRouter. Each provider shows its service's logo, or an icon or image you pick. Crowded servers can show only the models you tick.
- **A model picker that knows what's online**: models that can't answer right now wait in a folded *Offline* section.
- **Tools through MCP** (stdio and Streamable HTTP), with Allow once / Always allow / Deny for every call.
- **Skills** in the Agent Skills format: instructions, references and scripts that models load when a task calls for them.
- **Thinking models done right**: effort from Off to Max, a folding "Thought for 12 s" section, and reasoning sent back across tool calls.
- **Kind to your server's cache**: requests only ever grow at the end, so local servers reuse their prompt cache.
- **Edit, retry with any model, and branch**; streaming that survives closing the window; search; pins; presets; a profile models can know you by; a Stats page.
- **Holster-native**: your latest chats in the dock's preview, and a notification when a reply finishes in the background.

Everything stays on your PC: chats in a local database, API keys in Windows Credential Manager.
