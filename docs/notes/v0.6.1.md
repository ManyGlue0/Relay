Relay 0.6.1 makes adding a provider easier and smooths out two animations that lagged.

### Fixed

- **Paste the address the way the docs give it.** The base address, one ending in `/v1`, or the full endpoint (`…/v1/messages`, `…/v1/chat/completions`) all work now; a pasted endpoint used to end up doubled (`/v1/messages/messages`). Anthropic-compatible services that publish their address without `/v1` (like `https://api.z.ai/api/anthropic`) work as given. Under the field, Relay shows exactly where requests will go.
- **Testing an Anthropic-compatible service** sends the Messages API's headers when it lists the models.
- **The selected chat keeps up.** Dragging the sidebar wider or narrower no longer leaves the selection behind for a moment.
- **Tool cards stay put.** Web searches and other tool calls no longer slide after the chat while a reply scrolls it down.
