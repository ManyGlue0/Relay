Relay 0.6.0 adds web search for every model, speaks Anthropic's own API, and closes the holes a security review found before the public launch.

### New

- **Web search, for every model.** Turn on *Web search* in the composer's **+** menu. Claude uses Anthropic's own search and page reading; every other model gets Relay's: DuckDuckGo results and pages read as text, with no key or account.
- **Claude, natively.** Set a provider's API to *Anthropic* (the Anthropic preset does it for you). Claude's thinking shows as a readable summary, its signed thinking and search results carry over between messages, and the conversation stays in Anthropic's prompt cache (5 minutes or an hour, in Settings).
- **A new composer.** One **+** menu holds *Add files*, the preset and the switches for Skills, MCPs and Web search. The model and its thinking effort share one chip next to it.

### Safer

- **Bad answers can't take Relay down.** A broken or hostile server, a web page or a malformed file used to be able to crash Relay or fill its memory. Every answer, page, file and script output now has a size limit, and Relay never trusts a number a server sends.
- **Web search stays on the web.** Relay's page reader can't be pointed at your computer or your local network, not by a redirect and not by a web address that leads back home.
- **Skill scripts take arguments, not commands.** A model can't slip a second command into a `.bat` or `.cmd` script's arguments.
- **Links open in your browser.** A link in a reply never opens inside a Relay window, and Relay's window never leaves Relay.
- **Keys stay with their server.** A server that redirects elsewhere doesn't get your key sent along, and the provider editor warns you when a key would cross the internet unencrypted (`http://`).
- **Deleted means deleted.** Deleting a chat wipes its text from the database files too.
- **Script files don't run by surprise.** *Open in its app* shows a `.bat`, `.vbs` and the like in Explorer instead of running it.
- **Up-to-date parts.** Newer SQLite, KaTeX and zip libraries, with their security fixes.

### Changed

- SpaceXAI is now called SpaceXSI, as in xAI's own docs.
- The send button is drawn as one shape, so its arrow stays centered at every size.
